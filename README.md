# AI Job Scam Detection System

AI + ML powered cybersecurity system that detects:
- Fake job posts
- Scam URLs
- Suspicious emails
- Fraud phone numbers
- Phishing attempts

Features:
- Machine Learning
- OCR
- VirusTotal API
- EmailRep API
- Google Safe Browsing API
- Streamlit UI# ScanShield
It's a webpage that can not only detect job scam in any platform but also can tell why it is a scam by using different apis and ml.
